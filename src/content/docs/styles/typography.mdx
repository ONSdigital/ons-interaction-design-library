## Overview

Text is the primary way users digest information and complete tasks. Good typographic principles establish a clear visual hierarchy and maximise legibility.

## Font

The primary font used in ONS digital products is [Open Sans](https://fonts.google.com/specimen/Open+Sans). Stylistic set 1 is used because it includes the more accessible open-tail lowercase ‘g’ and serifed capital ‘I’.

Open Sans was chosen for its legibility, readability and extensive Unicode support. Font weight and size help establish hierarchy and distinguish between content.

Font family: `"Open Sans", "Helvetica Neue", Helvetica, Arial, sans-serif`

### Font weights

- **Bold:** 700
- Regular: 400

## Links

Links allow users to navigate between pages, websites and resources. They should behave consistently and predictably, allowing users to remain in control of their navigation.

### Link behaviour

Links should open in the current browser tab by default, including links to external websites and documents, unless there is a clear user need for them to open in a new tab

This maintains familiar browser behaviour, allowing users to return to the previous page using the back button or swipe-back gesture on mobile devices.

Users should be able to choose whether to open links in a new tab using their browser's functionality.

### External links

Links to external websites should behave in the same way as internal links.

- Do not automatically open external links in a new tab.
- Do not use external link icons.
- Use meaningful link text that makes the destination clear.

There is no need to explicitly state that a link leads to an external website.

This approach aligns with [GOV.UK guidance on removing external link icons](https://designnotes.blog.gov.uk/2016/11/28/removing-the-external-link-icon-from-gov-uk/).

### Opening links in a new tab

Avoid opening links in a new tab or window unless there is a clear user need.

Opening a new tab unexpectedly can disorient users, particularly those using assistive technologies or navigating on mobile devices. It can also prevent users from returning to their previous location using the browser back button.

An exception may be appropriate when navigating away would cause users to lose information entered into a form or interrupt an important task.

Where a new tab is necessary, include **(opens in new tab)** in the visible link text so users know what will happen before selecting the link.

Opening a new tab should not be based solely on whether a link leads to an external website or document.

### Accessibility

- **User control:** Users should remain in control of their navigation and be able to return to previous pages using familiar browser controls.
- **Predictable behaviour:** Links should open in the current tab unless there is a clear reason to do otherwise.
- **Meaningful link text:** Links should clearly describe their destination or purpose.
- **Keyboard accessibility:** Links must be accessible using a keyboard, with a visible focus state.
- **Screen reader users:** Unexpectedly opening a new tab can be disorienting. Always provide a visible warning when this behaviour is necessary.

For further information, see [WCAG Technique G200: Opening new windows and tabs only when necessary](https://www.w3.org/TR/WCAG20-TECHS/G200.html).
